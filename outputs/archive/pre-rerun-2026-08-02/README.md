## Known defects in this snapshot

These results were produced by the pipeline **before** the audit fixes. Do not cite
numbers from here without reading `AUDIT.md` first. Specifically:

- `Model 2C (add housing structure)` is byte-identical to `Model 1` for every
  outcome — the three `pct_*_units` columns were 100% NaN and were silently dropped.
  The archived `acs_predictors_ca_zip.csv` is the file that caused this.
- `Model 4` and `Model 4R` are the same regression.
- The analysis dataset carries duplicate `lat_x/lat_y/lon_x/lon_y` columns and a
  pseudo-county `"nan"` covering 777 unmatched ZIPs.
- Roughly 90 tables per directory are orphans from earlier notebook versions and
  cannot be regenerated by the current code. Among them, the `any_turbines | *`
  family is a binary wind specification that has since been restored to the notebook.
